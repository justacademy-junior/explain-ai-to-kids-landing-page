# Explain AI to Your Child: Interactive Landing Page

A fun, colourful and fully responsive landing page that helps parents **explain AI to their child and start learning together**. It uses simple words, everyday examples and two playable mini games, so artificial intelligence for kids feels friendly instead of scary.

Built with pure **HTML, CSS and JavaScript**. No frameworks, no build step, no dependencies.

## Features

- Playful header with a mobile menu and a sticky "Free Demo" button
- Hero with **Bit the robot**, whose eyes follow your cursor and who shares fun facts when tapped
- **Game 1: Spot the AI**. Tap everyday items to find which ones use AI, with a fun fact after each tap
- **Game 2: Teach Bit**. A tiny machine learning demo that shows how examples make AI smarter
- Age based tips for 4 to 7, 8 to 11 and 12 and up
- Flip card myth busters
- A five day learning plan for families
- Safety tips for parents
- Clear call to action cards and a full footer
- Responsive from small phones to large desktops
- Respects reduced motion settings and has visible keyboard focus
- SEO ready: title, meta description, Open Graph tags and JSON-LD

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

## Deploy on GitHub Pages

1. Push the files to a new GitHub repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. Your site will be live at `https://your-username.github.io/explain-ai-to-kids-landing-page/`.

## Customise

- **Colours:** edit the CSS variables at the top of the `<style>` block (`--grape`, `--bubble`, `--lemon`, `--mint`, `--sky`).
- **Games:** edit the `items` array (Spot the AI) and the `myths` array in the `<script>` block.
- **Fonts:** the page uses Fredoka and Nunito from Google Fonts, with safe fallbacks.
